# Party Invite

A flashy landing page for your house party invite. The hero asks **"Is this a ____ PARTY?"** while random party themes spin through like a roulette wheel.

## Stack

- React 19 + TypeScript
- Vite 6

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). Halloween: [http://localhost:5173/halloween/](http://localhost:5173/halloween/).

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit party theme words in `src/data/partyWords.ts`. Halloween opposites live in `src/data/opposites.ts`.
